# 出席點名 APP

教會用的出席點名與統計工具。電腦與手機皆可使用，資料只存在本機瀏覽器，不需安裝、不需網路。

詳細規格見 [docs/規格書.md](docs/規格書.md)。

## 使用方式

1. 直接用瀏覽器開啟 `index.html`（建議 Chrome 或 Edge）。
2. 到「設定」填入團體名稱與小組清單。
3. 到「場次」新增聚會場次，或直接到「成員」新增名單。
4. 回到「點名」頁，逐一點按狀態，或勾選後批次標記。
5. 點名完成後按「完成點名」，統計才會計入。
6. 定期到「設定」匯出備份 JSON。

## 注意事項

- 資料存在這台裝置的瀏覽器中。清除瀏覽器資料、換機或換瀏覽器前，請先匯出備份。
- 匯入備份會覆蓋目前所有資料。
- 請只開一個 APP 分頁，避免多個分頁互相覆蓋。

## 開發與測試

```bash
cd attendance-app
node --test tests/store.test.js   # 資料層與統計單元測試（需 Node 18+）
```

目錄結構：

```
index.html          頁面
css/style.css      樣式
js/store.js        資料層與統計（純函式）
js/app.js          畫面與事件
tests/             單元測試
docs/規格書.md      規格書
```
