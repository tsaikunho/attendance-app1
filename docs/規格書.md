# 出席點名 APP 規格書

版本：1.0　日期：2026-11-08　狀態：已完成首版交付

> 撰寫對象：專案負責人、開發者、教會行政同工。

## 1. 專案目標

提供教會（小組、主日、聚會）使用的出席點名工具，支援電腦與手機，資料僅存於本機，並能產出出席統計與關懷名單。

## 2. 已確認的規劃選項

| 項目 | 選擇 | 本規格的落實方式 |
| --- | --- | --- |
| 使用場合 | church（教會） | 預設場次類型為主日崇拜、晚間聚會、禱告會、小組聚會、特別聚會；提供關懷名單功能 |
| 人數 | 100 | 單頁一次載入全部成員；列表、統計在 100 人規模下即時反應（不分頁） |
| 點名方式 | multi | 解讀為「多種點名方式並存」：單人點選、依姓名搜尋、依小組篩選、勾選後批次標記、一鍵「未點名者全部出席」 |
| 裝置 | both | 響應式網頁（RWD），手機版 2 欄按鈕、電腦版 4 欄；不需安裝 |
| 資料儲存 | local | 資料存於瀏覽器 localStorage，另提供 JSON 備份匯出／匯入 |

## 3. 使用者與角色

- **點名人員**（同工、小組長）：建立場次、點名、查看統計。
- 本版不做帳號登入與權限分級（資料只在單一裝置，見第 9 節風險）。

## 4. 功能需求

### 4.1 點名（首頁）

- F-01 選擇場次：下拉列出所有場次，最新日期在前；完成的場次標示 ✓。
- F-02 小組篩選、姓名搜尋（即時篩選，不會遺失輸入焦點）。
- F-03 每位成員四種狀態按鈕：出席、遲到、請假、缺席。再按一次同一按鈕即取消（回到未點名）。
- F-04 即時摘要：應到、出席、遲到、請假、缺席、未點名、出席率。
- F-05 批次操作：勾選多人後一次標為指定狀態；可全選本頁、取消勾選。
- F-06 「未點名者全部出席」：快速處理多數人都到的情況。
- F-07 完成點名／重新開啟點名。完成後的場次才計入統計。

### 4.2 場次

- F-10 新增場次：日期（必填）、類型、標題（選填，留空則用類型名稱）。
- F-11 場次列表：顯示出席率與完成狀態；可直接跳到點名、切換完成、刪除。
- F-12 刪除場次會連同該場次所有點名紀錄一併刪除（需確認）。

### 4.3 成員

- F-20 新增成員：姓名（必填、不可全空白）、小組、電話（選填）。
- F-21 編輯姓名與小組。
- F-22 停用／啟用：停用成員不計入應到與統計，但保留歷史紀錄。本版不提供實體刪除，以保護歷史資料。
- F-23 依小組篩選名單。

### 4.4 統計

- F-30 日期區間篩選（起訖皆可空白＝全部）。
- F-31 總覽：已完成場次數、平均出席率、關懷名單人數。
- F-32 近期出席趨勢：最近 12 場已完成場次的出席人數長條圖。
- F-33 關懷名單：連續缺席達門檻（預設 3 場，可於設定調整）的成員。
- F-34 小組出席率表。
- F-35 成員出席統計表（依出席率由低到高排序，便於關懷）。
- F-36 匯出點名明細 CSV（UTF-8 含 BOM，Excel 可直接開啟），欄位：日期、場次、場次類型、小組、姓名、狀態。

### 4.5 設定與備份

- F-40 設定團體名稱、小組清單（逗號、頓號或換行分隔）、關懷門檻。
- F-41 匯出備份 JSON；匯入備份（會覆蓋現有資料，需確認，並先驗證格式）。
- F-42 清除全部資料（需確認）。

## 5. 統計定義（重要）

| 指標 | 定義 |
| --- | --- |
| 應到人數 | 啟用中的成員數 |
| 出席 | 狀態為「出席」或「遲到」（遲到視為到場） |
| 應出席（分母） | 應到人數 − 請假 |
| 出席率 | 出席 ÷ 應出席。無應出席人數時顯示 — |
| 未點名 | 場次完成前未設定狀態。單場摘要中僅作提示；**統計（成員、小組）時視為缺席** |
| 連續缺席 | 從最近一場已完成場次往回算，遇到出席、遲到或請假即中斷 |
| 統計範圍 | 僅已完成點名的場次 |

## 6. 資料庫設計（本機 localStorage）

本版採單一 JSON 文件，儲存鍵名 `attendance-app:v1`，無需外部資料庫。

```json
{
  "version": 1,
  "settings": { "churchName": "string", "groups": ["string"], "alertWeeks": 3 },
  "members": [
    { "id": "m…", "name": "string", "group": "string", "phone": "string",
      "active": true, "createdAt": "ISO-8601" }
  ],
  "services": [
    { "id": "s…", "date": "YYYY-MM-DD", "title": "string", "type": "string",
      "completed": false, "createdAt": "ISO-8601" }
  ],
  "records": {
    "<serviceId>|<memberId>": { "status": "present|late|leave|absent", "time": "ISO-8601" }
  }
}
```

設計說明：

- `records` 以「場次ID|成員ID」為鍵，點名寫入與查詢皆為 O(1)，100 人 × 每年 60 場約 6,000 筆，遠低於 localStorage 約 5 MB 上限。
- 未點名＝無紀錄，不另存狀態，避免資料不一致。
- 成員與場次不做實體刪除（成員用停用），場次刪除時級聯刪除紀錄。
- `version` 欄位保留給未來的結構遷移。

## 7. 操作流程

1. **初次設定**：設定 → 填團體名稱與小組清單。
2. **建立場次**：場次 → 選日期與類型 → 新增場次（自動跳到點名頁）。
3. **點名**：點名頁 → 逐一點按狀態；人多時用「小組」與「搜尋」縮小範圍；勾選後批次標記；最後按「未點名者全部出席」。
4. **完成**：按「完成點名」，統計即時計入。發現錯誤可「重新開啟點名」更正。
5. **查看統計**：統計頁 → 設定日期區間 → 檢視關懷名單，必要時匯出 CSV。
6. **備份**：設定 → 匯出備份 JSON（建議每週一次，並存到雲端硬碟）。

## 8. 非功能需求與技術架構

| 項目 | 規格 |
| --- | --- |
| 技術 | 原生 HTML／CSS／JavaScript（ES2017+），無框架、無外部相依，無需建置 |
| 執行方式 | 直接以瀏覽器開啟 `index.html`；建議放在本機或內網以避免瀏覽器限制 |
| 瀏覽器 | 近兩年的 Chrome、Edge、Safari、Firefox（電腦與手機） |
| 版面 | RWD；手機版 16 px 側邊距、無水平捲動、按鈕高度 ≥ 44 px |
| 深色模式 | 依系統設定自動切換 |
| 離線 | 完全離線可用（無 CDN 依賴） |
| 效能 | 以 100 人為設計上限；每次操作皆為整頁區塊重新渲染（未做效能量測，列為實機待測項目） |
| 隱私 | 資料不上傳任何伺服器；CSV 與備份由使用者自行保管 |
| 無障礙 | 按鈕具 aria-pressed，勾選框具 aria-label，狀態不只靠顏色（有文字） |

檔案結構：

```
attendance-app/
├── index.html          頁面框架與分頁
├── css/style.css       樣式（含深色模式與手機版）
├── js/store.js         資料層與統計（純函式，可獨立測試）
├── js/app.js           畫面渲染與事件處理
├── tests/store.test.js 單元測試（Node 內建 test runner）
├── docs/規格書.md       本文件
└── README.md           使用與測試說明
```

## 9. 風險與限制

| 風險 | 影響 | 對策 |
| --- | --- | --- |
| 資料只存於單一瀏覽器，清除瀏覽資料即遺失 | 高 | 設定頁提供備份；建議每週匯出一次 |
| 多台裝置各自點名，資料不會同步 | 中 | 目前規定由一台主要裝置負責點名；若需多人同時點名，需升級為雲端方案（見第 12 節） |
| 同一瀏覽器開多個分頁時，每個分頁各自保有資料副本，後操作的分頁會覆蓋先前的變更 | 中 | 只開一個 APP 分頁；需要時重新整理頁面 |
| 不同瀏覽器（如 Chrome 與 Edge）的資料互不相通 | 中 | 同一台裝置固定使用一個瀏覽器 |

## 12. 後續擴充（非本版範圍）

- 多人同時點名：導入雲端資料庫（如 Firebase Firestore）與帳號驗證。
- 依姓名匯入成員（CSV 匯入）、批次編輯。
- 出席統計以 PDF 或 Excel 報表輸出。
- 推播或簡訊通知關懷名單成員。
- 支援 QR code 自助簽到。
